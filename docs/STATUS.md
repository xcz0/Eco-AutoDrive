# 项目状态

**更新日期**：2026-08-06  
**当前里程碑**：基础代码构建与评测口径收敛阶段。已完成 Diffusion Planner 基线、无交通闭环和通用交通观测接口。下一步优先建立稳定的短程或中程能耗场景；强化学习、预瞄注入和最终能耗方案仍待确定。

## 已完成

### Diffusion Planner 基线

- 已实现与官方 checkpoint 参数层级兼容的模型主体、Encoder、DiT、归一化和 10 步 DPM-Solver++ baseline sampler；
- 已实现严格 EMA 权重加载、key、形状和参数量校验；
- 已有合成 observation、噪声和输出契约测试；
- 同一 CPU 输入和噪声下，本实现与上游最终输出最大绝对误差为 `3.1e-5`，既定容差为 `atol=5e-5, rtol=0`。

### MetaDrive 闭环

- 已实现 `MetaDriveMapAdapter`、`TrajectoryMetaDriveEnv` 和 `KinematicTrajectoryPolicy`；
- 已实现无交通和通用有交通观测适配器；
- 地图适配器可构造固定形状的普通 lane、route lane 和限速张量；
- 有交通适配器支持 10 Hz 快照、稳定 ID、`[32,21,11]` 邻车历史和 `[5,10]` 静态物体；
- `scripts/evaluate.py` 可使用官方 EMA、固定噪声生成器和滚动重规划运行闭环；
- 每次评测保存 resolved config、raw observation、噪声、完整预测、目标与实际状态、执行误差、summary 和可选 GIF；
- 已修正 PGMap 限速哨兵、轨迹执行时序、曲线 lane 标量校验、交通历史事务性和矩阵汇总问题。

### 已完成评测

- Windows CPU 的无交通 `S`/`SC`、噪声 seeds `0..4`、20 s 上限矩阵已完成且无碰撞或出界；
- 已完成有交通长路线 seeds `0..2`、密度 `0.05/0.10`、两条路线的 12 回合部分矩阵；
- 长路线 12 回合产物和接口门槛通过，但背景仿真车辆在长时运行中出现异常行为，随后触发自车碰撞或出界；该矩阵不作为规划器基本驾驶能力或能耗性能基线；
- 中程、低密度场景可正常行驶，后续评测将围绕稳定、能表达过弯、变道和限速变化的场景展开。

## 已验证结论

| 结论 | 证据范围 | 结论边界 |
| --- | --- | --- |
| 官方 EMA 可严格加载并稳定推理 | 固定资产、CPU 合成输入和自动化测试 | 不等于复现官方 nuPlan 闭环指标 |
| 移植模型与上游最终输出数值接近 | 固定输入与噪声，最大误差 `3.1e-5` | 尚未完成真实 nuPlan 场景逐层对照 |
| PGMap 未设置限速不能作为有效限速进入模型 | `S`/`SC` simulator 回归 | 不覆盖所有程序化地图语义 |
| 运动学执行器可逐点匹配 waypoint | 直线和变 heading 回归 | 不证明低层车辆动力学可跟踪 |
| 无交通 `S`/`SC` 在 seeds `0..4` 下无闭环失败 | Windows CPU、20 s 上限 | 不代表有交通或长程性能 |
| 通用交通观测满足 21 帧、10 Hz 和稳定 ID 契约 | 单元测试、simulator 测试和已保存 trace | 不证明与 nuPlan 交通分布一致 |
| 长时高交通量矩阵受到背景车辆异常行为干扰 | 已完成的 12 个长路线回合 | 不用于否定规划器的中程基本驾驶能力 |

1. 定义短程或中程场景集合，覆盖巡航、过弯、变道和限速变化，并控制背景车辆数量；

5. 结合 `RESEARCH.md` 逐步确定预瞄信息和强化学习路线。

所有运行都应保留 trace、配置和终止状态；不得通过后处理、回退控制器或挑选特定 seed 掩盖结果。
