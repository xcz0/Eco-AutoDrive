# 研究设想

本文记录尚未确定、尚未实现或仅用于讨论的研究方向。这里的内容不构成当前系统契约，也不能被描述为已完成功能。

## 研究目标

研究如何在保留预训练 Diffusion Planner 驾驶能力的前提下，引入道路预瞄信息，使规划轨迹在安全、进度和旅行效率可接受的条件下表现出更好的能耗特性。

当前重点不是超长距离驾驶，而是建立能够稳定表达能耗影响机制的闭环场景，例如：

- 直道巡航；
- 单弯和连续弯道；
- 变道与合流；
- 限速变化；
- 少量背景车辆导致的速度调整。

## 整体研究路线

```text
预训练 Diffusion Planner
  -> MetaDrive 稳定短程/中程场景
  -> 记录轨迹、安全、进度和能耗指标
  -> 加入道路预瞄条件
  -> 比较预瞄前后的轨迹与能耗变化
  -> 视结果决定是否进行强化学习微调
  -> 使用更精细能耗模型复核
```

该路线只确定研究顺序，不预先固定强化学习算法、奖励函数或网络注入结构。

## 强化学习方向

强化学习可用于利用闭环环境奖励微调预训练扩散规划器，但具体方案仍待确定。可能需要研究：

- 采用 DPPO、普通环境 MDP 下的扩散策略优化，或其他适合扩散策略的方法；
- 更新完整模型、只训练新增模块，或采用参数高效微调；
- 如何在保持原始驾驶能力的同时优化能耗；
- 如何定义与实际执行轨迹一致的策略动作和概率；
- 如何处理安全、进度、旅行时间、舒适性和能耗之间的关系；
- 是否先做监督式或代价引导实验，再决定是否需要强化学习。

在这些问题确定前，项目文档和代码不应规定具体 sampler、log-prob、critic、优势估计、PPO 更新或固定奖励公式。

## 道路预瞄信息

可能的预瞄信息包括：

- 路线前方曲率；
- 限速及限速变化位置；
- 变道、合流和道路拓扑；
- 前方交通状态；
- 在具备数据时加入坡度、高程或其他道路属性。

可能的使用方式包括独立条件编码、路线 token 扩展、条件残差或推理期引导。具体预瞄距离、采样方式、编码器和注入位置均待实验确定。

研究时需要区分：现有 `route_lanes` 已提供的局部几何，与新增的更远期或更明确的预瞄信息。新增模块应能够与原始基线公平比较，但具体等价性约束尚未确定。

## 能耗评价

MetaDrive 内置能耗可以作为同一环境和车辆配置下的初步代理指标，但不能直接解释为真实车辆燃油或电能消耗。后续可考虑使用 FASTSim 或其他车辆模型对实际执行速度 trace 做复核。

需要进一步确定：

- 研究对象是燃油车、电动车还是一般化车辆；
- 使用总能耗、单位距离能耗、单位有效进度能耗或其他指标；
- 如何处理停车、低速拖延和任务失败造成的伪节能；
- 不同场景长度和终止类型之间如何比较；
- 是否需要加速度、坡度、车辆质量、空气阻力和动力系统效率等信息；
- 代理指标与精细模型结论不一致时采用何种解释口径。

所有评测场景都应进入分析。完成、时间截断、碰撞、出界和仿真异常分别标注，再根据场景是否可比解释能耗结果，而不是只保留成功回合。

## 运动学执行的局限

当前环境直接执行规划轨迹点，因此可以隔离验证规划器、地图、观测和闭环重规划，但不能表示真实 steering、throttle、brake 和车辆动力学限制。

这意味着当前能耗结果主要反映规划轨迹及其速度变化在运动学执行条件下的相对差异，不能直接推出：

- 轨迹能够被真实低层控制器精确跟踪；
- 横向和纵向动力学约束均满足；
- 精细车辆能耗模型在真实执行时得到相同结论。

该局限现阶段不阻塞研究，但必须随结果一起说明。低层控制和动力学验证可作为后续独立阶段。

## 交通历史预热

现有方法是在 ego 静止时让背景交通运行 2 s，以获得真实 21 帧历史。它优于简单重复 reset 帧，因为背景车辆历史是真实演化的；但静止 ego 会影响附近交通车辆的决策。

可比较的方案包括：

1. 重复 reset 帧：实现简单且不扰动交通，但历史不真实；
2. 静止 ego 真实预热：已有实现，历史真实，但会改变交通初态；
3. 使用其他控制器预热 ego：历史较自然，但引入额外策略并改变初始锚点；
4. 背景交通独立预热：ego 在预热期间不参与碰撞和交通交互，正式评测时再以固定锚点加入。

当前认为第 4 种更适合作为目标方案。它能保留真实背景交通历史，同时减少静止 ego 对交通流的干扰。是否能在 MetaDrive 中稳定实现、对象 ID 是否连续以及预热后如何恢复正式场景，需要后续验证。

## 仿真长度与交通量

长时高交通量仿真中，背景车辆行为可能逐渐异常并主导碰撞或出界。由于研究目标是能耗，不必要求所有实验都采用 2–5 km 长路线。

场景长度和交通量应以“能否稳定表达研究因素”为依据。短程或中程场景只要能覆盖过弯、变道、合流、限速变化和有限交通交互，就可以用于主要方法比较。长时场景可保留为鲁棒性或仿真器诊断，不作为默认能耗基线。

## 待确定问题

- 哪些场景能够稳定、重复地表现主要能耗影响因素；
- 道路预瞄的内容、距离和表示方式；
- 是否需要强化学习，以及采用哪类扩散策略优化方法；
- 能耗主指标、车辆模型和约束口径；
- 运动学结果与后续低层动力学结果如何衔接；
- 背景交通独立预热在 MetaDrive 中的可实现性；
- 如何对不同终止类型的场景进行公平比较。
