# 阶段 0：可复现 Diffusion Planner 独立基线

## 目的与边界

阶段 0 验证官方 Diffusion Planner EMA checkpoint 能被本项目的最小、checkpoint 兼容推理实现严格加载。它使用固定合成观测和显式噪声运行原始的 10 步 DPM-Solver++，并不安装 nuPlan、不访问 nuPlan 数据集，也不声称复现官方闭环指标。

本阶段不导入 `ref/`。nuPlan 数据处理、闭环 planner 封装和 classifier guidance 不属于阶段 0；MetaDrive 闭环从阶段 1 开始实现。

## 验证命令

在 CPU 上运行：

```powershell
uv run pytest tests/smoke/test_stage0_baseline.py -m slow -s
```

smoke 测试在哈希不匹配、EMA key 不完整、checkpoint 参数数不符、输出出现 NaN/Inf 或同一输入重复推理不一致时失败；成功时输出一行 JSON 报告。checkpoint 的异常输入契约由 `tests/integration/` 中的测试覆盖。
