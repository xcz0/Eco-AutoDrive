# Use stable feature-bearing scenarios for energy evaluation

Primary energy comparisons use short or medium, low-traffic scenarios that reproducibly expose cruising, curvature, lane changes or merges, speed-limit changes and limited interaction. Long, dense simulations remain useful for robustness diagnostics but are not the default baseline when background-traffic instability dominates the outcome.
